# Maewens Portfolio

Portfolio vitrine de Steve Christ Othniel Dedocoton.

## Personnalisation rapide

1. Photo
   - Mets ta photo dans `assets/`.
   - Exemple : `assets/steve.jpg`.
   - Dans `index.html`, remplace :
     `src="assets/profile-placeholder.svg"`
     par :
     `src="assets/steve.jpg"`.

2. WhatsApp
   - Ouvre `script.js`.
   - Remplace `2250000000000` par ton numéro avec indicatif pays, sans `+` ni espace.
   - Exemple : `2250700000000`.

3. CV
   - Mets ton CV PDF dans `assets/`.
   - Renomme-le `CV_Steve_Dedocoton.pdf`.

4. Projets
   - Dans `index.html`, duplique une carte `.project-card`.
   - Remplace le titre, la description, les technologies et le lien `href="#"`.

5. Niveau des compétences
   - Les pourcentages sont des valeurs de démonstration.
   - Ajuste-les selon ton niveau réel.

## Lancer le site

Double-clique sur `index.html`, ou utilise l'extension Live Server dans VS Code.
