Maewens Portfolio

Présentation

Maewens Portfolio est un portfolio professionnel de Steve Christ Othniel Dedocoton, informaticien spécialisé dans son développement de compétences en développement web et en réseau informatique.

Ce site présente son profil, ses compétences, ses projets et ses moyens de contact.

Fonctionnalités

- Présentation personnelle et professionnelle.
- Section À propos.
- Présentation des compétences web et réseau.
- Affichage des compétences avec des barres de progression.
- Présentation des projets réalisés.
- Filtrage des projets par catégorie.
- Consultation et téléchargement du CV au format PDF.
- Contact direct via WhatsApp.
- Interface moderne avec effets visuels.
- Bouton de retour en haut de page.

 Technologies utilisées

- **HTML5** : structure du site.
- **CSS3** : design et mise en page responsive.
- **JavaScript** : interactions et fonctionnalités dynamiques.

Installation

1. Télécharge ou clone le dépôt GitHub.
2. Ouvre le dossier dans Visual Studio Code.
3. Vérifie que les fichiers HTML, CSS, JavaScript et les ressources sont présents.
4. Ouvre `index.html` dans ton navigateur.

Pour faciliter le développement, tu peux utiliser l'extension Live Server de Visual Studio Code.

 Déploiement avec GitHub Pages

1. Ouvre le dépôt GitHub.
2. Accède à **Settings → Pages**.
3. Dans la section Build and deployment, sélectionne **Deploy from a branch**.
4. Choisis la branche `main` et le dossier `/ (root)`, si les fichiers du site se trouvent à la racine.
5. Clique sur **Save**.
6. Attends la publication et récupère l'adresse fournie dans la section Pages.

 Personnalisation

- `index.html` : modifier les textes, les projets et les liens.
- `style.css` : modifier les couleurs, les animations et la mise en page.
- `script.js` : modifier les interactions et le comportement dynamique.
